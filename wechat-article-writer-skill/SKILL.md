# 微信公众号文案写作助手

## 任务目标
- 本Skill用于：快速生成高质量的微信公众号文案，从内容创作、配图生成再到自动排版的一站式服务
- 能力包含：
  1. 检索近期热点和热门选题
  2. 以金枪大叔的写作风格生成1500字左右的公众号文案
  3. 自动生成正文配图和封面图
  4. 自动完成文章排版优化（适合公众号展示）
  5. 生成可直接复制到公众号的HTML文件（保留完整排版）
  6. 提供发布到公众号的操作指引
- 触发条件：用户提供创作主题/想法，说"帮我写一篇公众号文章"或类似表达

## 前置准备
- 依赖说明：scripts脚本所需的依赖包及版本
  ```
  markdown>=3.4.0
  beautifulsoup4>=4.12.0
  ```

## 操作步骤

### 标准流程

**步骤1：热点选题**
基于用户提供的主题，智能体将：

1. **检索近期热点**：
   - 搜索与主题相关的近期热点事件、热门话题
   - 筛选1-3个最具传播潜力的切入点
   - 分析热点与用户主题的关联性，确定最佳切入点

**热点选题参考**：见 [references/hot-topic-search.md](references/hot-topic-search.md)

**金枪大叔写作风格参考**：见 [references/jinqiang-uncle-style-guide.md](references/jinqiang-uncle-style-guide.md)（金枪大叔写作风格指南）

**步骤2：文章创作**
以金枪大叔的写作风格创作文章：

**金枪大叔写作风格特点**：
- **语言风格**：犀利直接、观点鲜明、一针见血
- **表达方式**：金句频出、对比强烈、直击痛点
- **结构特点**：观点先行、层层展开、用数据和案例支撑
- **句式特点**：短句为主、节奏紧凑、多用反问和排比
- **内容特点**：洞察人性、揭露本质、引发思考

1. **生成文章结构**：
   - 拟定大纲：3-5个主要章节，每个章节2-3个要点
   - 设计开头：抛出观点、制造冲突、抓住注意力

2. **撰写正文内容**：
   - 字数控制在1500~3000字左右（可根据用户要求调整）
   - 保持金枪大叔的语言风格：犀利、直接、观点鲜明、金句频出
   - 使用对比、反问、排比等修辞手法，增强表达力
   - 短句为主，节奏紧凑，善用金句和总结性语言
   - 穿插热点话题和实际案例，增强可读性。必须使用最新热点案例（优先使用最近1-2个月内的热门AI工具或事件），避免使用过时案例。** 科技类文章尤其要注意时效性，如使用Clawdbot、Grok-3、DeepSeek等最新AI工具作为案例，而非ChatGPT等早期工具。案例需包含具体时间点、数据支撑和具体场景，如"上周发布的Clawdbot V3版本"或"某机构测试显示转化率提升40%"。
   - 洞察人性，揭露本质，引发读者思考
   - 设计结尾：总结观点、给出建议、留下深刻印象

3. **优化润色**：
   - 检查段落逻辑是否连贯
   - 确保观点清晰、论证有力
   - 调整语言表达，符合金枪大叔风格
   - 提炼金句，强化核心观点

4. **生成爆款标题**（文章完成后）：
   - 基于完成的文章内容，提炼核心亮点和关键信息
   - 确定标题：**高点击率爆款标题**，符合金枪大叔的标题风格，直击痛点，长度10-16字
   - 标题生成参考：见 [references/viral-title-best-practices.md](references/viral-title-best-practices.md)
     - **核心内容**：爆款标题特质、设计要素、不同赛道风格（科技/情感/职场/教育/理财/健康/美食/旅游/时尚）
     - **生成方法**：5步法生成流程、6种标题模板（数字型/疑问句/对比句/金句型/感叹句/痛点型）
     - **高级技巧**：多维度组合、情绪引导、时效性、社交属性
     - **实战案例**：失败案例分析和AB测试对比实例
   - 生成多个标题备选（3-5个），选择最优标题
   - 确保标题与文章内容高度匹配，避免标题党

**步骤3：配图生成**
智能体将为文章生成配图：

1. **生成封面图**：
   - 根据文章主题和风格，生成一张高质量的封面图
   - 使用步骤2生成的爆款标题作为封面生图的风格主题参考，美观协调
   - 封面不要带文字
   - 尺寸规格：严格为900×383像素（2.35:1比例）
   - 设计要求：遵循爆款封面设计原则，确保视觉冲击力、信息传达效率、品牌辨识度
     - 封面设计参考：见 [references/cover-design-best-practices.md](references/cover-design-best-practices.md)
       - **核心内容**：爆款封面特质、设计要素（构图/色彩/文字/元素）、不同赛道风格详解
       - **更多风格**：插画风格、真人写实风格、极简风格、3DCg风格、油画风格、赛博朋克风格
       - **实例库**：8个不同赛道的封面设计实例（科技/情感/职场/教育/理财/健康/美食/旅游）
       - **工具资源**：设计工具推荐、图片资源、配色工具
   - 构图：简洁大气，突出核心信息，留白充足
   - 色彩：符合赛道风格
   - 风格适配：
     - 科技类：深蓝色调、科技元素
     - 情感类：温暖色调、柔和元素
     - 职场类：专业色调、商务元素
     - 教育类：成长色调、教育元素
     - 理财类：金色色调、图表元素
     - 健康类：绿色色调、健康元素
     - 美食类：暖橙色调、美食元素
     - 旅游类：风景色调、实景元素

2. **生成正文配图**：
   - 根据每个主要章节的内容，生成2-4张正文配图
   - 风格要求：与文章风格匹配、图文相关、美观协调
   - 尺寸建议：900×500像素（16:9比例）

3. **图片命名**：
   - 封面图：`封面图.png`
   - 正文配图：`配图1.png`、`配图2.png`等

**步骤4：自动排版优化**
智能体将为文章进行专业的公众号排版优化：

1. **结构优化**：
   - 添加吸引眼球的标题（加大加粗）
   - 设置简短摘要或引语（用引用样式）
   - 合理划分段落（每段3-5句话，避免过长）
   - 使用小标题分割内容（三级或四级标题）
   - **注意：不使用分隔线**

2. **视觉优化**：
   - 重点内容加粗（关键词、核心观点）
   - 金句和重要数据用引用样式突出
   - 关键数字使用特殊标记（如>100万）
   - 列表化要点（使用有序或无序列表）
   - 长段落拆分为短句，提升可读性

3. **配图插入位置**：
   - 封面小图在文章最前面，随后为开头引语
   - 每个小标题后插入正文配图
   - 金句或重点内容后插入装饰性图片
   - 结尾总结前插入图片引导阅读

4. **互动设计**：
   - 文章结尾添加引导互动的话语
   - 设置问题引导读者留言

5. **排版样式示例**：
   ```
   [大标题：加粗、24号字]

   [摘要/引语：引用样式、16号字、灰色]

   [小标题1：加粗、18号字]

   [正文段落：16号字、行间距1.75]
   **重点内容加粗**，普通内容保持原样。

   > 金句或重要观点用引用样式

   [配图插入位置]

   - 要点1：使用列表
   - 要点2：清晰明了
   - 要点3：易于阅读

   [小标题2：加粗、18号字]

   [正文段落：16号字、行间距1.75]

   [结尾：引导互动]
   你怎么看？欢迎在评论区留言讨论~
   点赞和"在看"，是对我最好的支持👇
   ```

**排版优化参考**：见 [references/formatting-best-practices.md](references/formatting-best-practices.md)（公众号排版的专业技巧和样式指南）


**步骤5：质量检查与最终交付**
- 文案检查：
  - 标题吸引力（评分 1-10）
  - 正文流畅度和可读性
  - 情绪共鸣强度
  - 行动指令清晰度
  - 检查文案是否存在常识性与合理性错误
  - **案例时效性检查**：确保使用最新热点案例（1-2个月内）
  - **案例完整性检查**：包含具体时间点、数据支撑和应用场景
    
- 配图检查：
  - 图片与文案内容匹配度
  - 视觉风格一致性
  - 图片质量和细节
  - 整体审美评分
- 排版检查：
  - 检查是否有重复分隔线，有就去掉多余分隔线，只保留一条
- 优化建议：
  - 列出可改进点
  - 提供优化方案,并自行进行优化修改
  - 给出最终发布建议

**步骤6：生成HTML文件**
智能体将调用脚本生成可直接复制的HTML文件：

1. **脚本调用**：
   - 调用 `scripts/generate_html.py` 处理Markdown格式文章
   - 如果有图片文件，自动以base64格式嵌入到HTML中
   - 生成包含完整内联样式的HTML文件
   - HTML文件可在浏览器中直接打开

2. **样式优化**：
   - 所有样式内联，确保复制到公众号后保持效果
   - 标题、段落、引用、列表等元素都有对应样式
   - 图片占位符更友好，明确标注尺寸要求

3. **图片处理说明**：
   - **情况1：智能体能提供图片URL**（推荐）
     - 智能体生成图片后，提供图片的URL链接
     - 在Markdown中使用URL格式：`![封面图](https://xxx.png)`
     - HTML会直接使用URL，无需额外处理
     - 复制到公众号后，图片会自动加载

   - **情况2：有本地图片文件**
     - 智能体将图片保存到 `./images` 目录
     - 图片命名：`封面图.png`、`配图1.png`、`配图2.png`等
     - 调用脚本：`python generate_html.py article.md article.html ./images`
     - 图片会自动转换为base64并嵌入到HTML中
     - 复制到公众号后，图片自动显示

   - **情况3：没有图片文件或URL**（默认）
     - 使用占位符：`📌 [图片描述]`
     - 明确标注建议尺寸：
       - 封面图：900×383像素（2.35:1比例）
       - 正文配图：900×500像素（16:9比例）
     - 提示用户上传配图或提供图片URL
