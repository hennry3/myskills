## 主角设定模板

### 1. 逆袭型主角
**适用场景**：修仙、武侠、都市职场

**设定框架**
```
姓名：[如林萧、叶辰、苏铭]
初始身份：
  - 废柴少爷（修仙/武侠）
  - 被开除的员工（都市职场）
  - 被背叛的门徒（修仙）
性格特质：
  - 隐忍腹黑（表面顺从，内心谋划）
  - 桀骜不驯（不服输，敢对抗权威）
  - 扮猪吃虎（隐藏实力，关键时刻爆发）
核心执念：
  - 复仇（针对背叛/羞辱自己的人）
  - 登顶巅峰（证明自己的实力）
  - 守护某人（家人/爱人/恩师）
```

**经典案例**
- 林萧（废柴少爷→修仙天才）
- 叶辰（底层打工人→商界巨擘）
- 苏铭（被背叛门徒→新宗主）

### 2. 穿越重生型主角
**适用场景**：历史、玄幻、都市

**设定框架**
```
姓名：[现代名字/古代化名]
穿越身份：
  - 皇子/公主（历史）
  - 废柴少主（玄幻）
  - 平民百姓（历史/都市）
性格特质：
  - 拥有现代知识/思维
  - 对未来有预知能力
  - 利用信息差优势
核心执念：
  - 改变命运（改变原主的悲惨结局）
  - 历史变革（推动历史进程）
  - 改变世界（用现代思想改造古代）
```

**经典案例**
- 李云（现代程序员→古代发明家）
- 楚天歌（现代医生→古代神医）
- 赵天（现代高管→古代谋士）

### 3. 系统流主角
**适用场景**：都市、末世、玄幻

**设定框架**
```
姓名：[普通名字]
系统类型：
  - 修炼系统（修仙/玄幻）
  - 技能系统（都市/末世）
  - 收集系统（各种类型）
性格特质：
  - 起初平凡，逐步成长
  - 系统引导下快速变强
  - 目标明确，行动果断
核心执念：
  - 完成系统任务
  - 解锁系统全部功能
  - 成为系统最强宿主
系统互动方式：
  - 心灵感应（脑海中直接交流）
  - 视野界面（系统UI显示）
  - 提示类型（警告/建议/任务）
宿主与系统关系：
  - 从陌生到熟悉
  - 从质疑到信任
  - 逐渐形成默契配合
```

**经典案例**
- 王风（都市神豪系统）
- 陈阳（末世生存系统）
- 张三（修仙加速系统）

**系统互动示例**
```
系统：检测到危险，建议立即撤离。
宿主：有多危险？
系统：三名筑基期修士，敌意值85%。
宿主：撤离成功率？
系统：60%，但会暴露位置，引来更多追兵。
宿主：那主动出击？
系统：推荐方案：先解决实力较弱的那个，胜率70%。
宿主：好，就按你说的办。
```

## 金手指设定模板

### 1. 祖传宝物型
**适用场景**：修仙、武侠

**设定框架**
```
名称：[如祖传玉佩、上古戒子]
外观描述：[简短描述物品外观]
核心能力：
  - 智慧传承（老爷爷/意识传承）
  - 空间存储（内部空间）
  - 功法加速（修炼速度提升）
升级路径：
  - 收集能量/材料升级
  - 完成特定任务解锁
  - 吸收天地灵气觉醒
使用限制：
  - 每日使用次数限制
  - 需要消耗灵力/能量
  - 特定条件下才能激活
```

**经典案例**
- 祖传玉佩（老爷爷传承）
- 上古戒子（空间存储）
- 龙形吊坠（血脉觉醒）

### 2. 系统型
**适用场景**：都市、末世、玄幻

**设定框架**
```
系统名称：[如神豪系统、无敌系统]
系统来源：[天降系统/穿越绑定/意外激活]
核心功能：
  - 任务系统（完成任务获奖励）
  - 商城系统（购买道具/技能）
  - 属性系统（查看/提升属性）
  - 分析系统（洞察/推演/预测）
系统互动：
  - 心灵感应（脑海直接交流）
  - 视野界面（系统UI显示）
  - 实时提示（警告/建议/分析）
升级机制：
  - 完成任务获得经验值
  - 解锁更高级功能
  - 系统等级提升
宿主成长：
  - 系统引导下快速变强
  - 从质疑到信任
  - 形成默契配合
副作用/限制：
  - 任务有失败惩罚
  - 部分功能需要点数/货币
  - 系统有冷却时间
```

**经典案例**
- 神豪系统（金钱无限）
- 无敌系统（实力无敌）
- 收集系统（收集万物）
- 分析系统（洞察弱点）

**系统互动示例（战斗中）**
```
系统：检测到敌方左肋灵力流动异常，疑似旧伤。
宿主：有多严重？
系统：建议攻击该位置，命中概率提升50%，伤害加成30%。
宿主：好，给我详细攻击路线。
系统：已规划三条路线，推荐路线一：从右侧切入，速度最快，耗时2秒。
宿主：就按路线一，准备。
系统：蓄力中...蓄力完成，随时可以发动。
宿主：动手！
```

**系统互动示例（日常）**
```
系统：宿主，检测到前方有宝物反应，距离300米。
宿主：什么宝物？
系统：初步判断为千年灵草，价值500点数。
宿主：500点...还不错。有没有风险？
系统：扫描周边...发现一名守护者，实力筑基中期，建议谨慎行事。
宿主：筑基中期...有点麻烦。系统能帮忙吗？
系统：可以提供对方弱点分析，命中率提升20%。
宿主：足够了，我去看看。
```

**经典案例**
- 神豪系统（金钱无限）
- 无敌系统（实力无敌）
- 收集系统（收集万物）

### 3. 血脉天赋型
**适用场景**：修仙、玄幻、异能

**设定框架**
```
血脉名称：[如龙族血脉、古神血脉]
觉醒条件：
  - 到达特定年龄
  - 遇到生死危机
  - 吞服觉醒丹药
核心能力：
  - 特殊属性强化（力量/速度/感知）
  - 特殊技能（龙息/神光）
  - 成长潜力（修炼速度快）
成长阶段：
  - 初期觉醒（展现部分能力）
  - 完全觉醒（全部能力解锁）
  - 进阶形态（血脉进化）
弱点/限制：
  - 血脉冲突（不同血脉排斥）
  - 觉醒过程痛苦
  - 需要特殊资源维持
```

**经典案例**
- 龙族血脉（力量与防御）
- 古神血脉（神通与威压）
- 元素血脉（元素亲和）

## 反派设定模板

### 1. 嫉妒型反派
**适用场景**：修仙、都市、校园

**设定框架**
```
姓名：[反派名字]
身份：
  - 天才师兄/同学（修仙/校园）
  - 公司高管（都市）
  - 家族继承人（各类）
性格特质：
  - 嫉妒心强（无法接受主角超过自己）
  - 心胸狭窄（手段阴险）
  - 狂妄自大（看不起主角）
恶行/动机：
  - 陷害主角（制造污名）
  - 抢夺机缘（夺走主角的宝物/机会）
  - 打压主角（利用势力压制）
实力/优势：
  - 初期实力高于主角
  - 有强大背景支持
  - 掌握资源/权力
```

**经典案例**
- 林峰（天才师兄）
- 王明（公司高管）
- 赵强（家族继承人）

### 2. 利益型反派
**适用场景**：商战、宗门、家族

**设定框架**
```
姓名：[反派名字]
身份：
  - 敌对家族族长
  - 竞争公司老板
  - 敌对宗门长老
性格特质：
  - 冷酷无情（为利益不择手段）
  - 精于算计（布局周密）
  - 虚伪狡诈（表面仁义）
恶行/动机：
  - 资源争夺（抢夺宝地/矿脉）
  - 势力扩张（吞并对手）
  - 利益最大化（不惜牺牲他人）
实力/优势：
  - 掌控大量资源
  - 有强大的势力网络
  - 拥有特殊手段（功法/宝物）
```

**经典案例**
- 王家族长（家族斗争）
- 张总（商业竞争）
- 天长老（宗门内斗）

### 3. 复仇型反派
**适用场景**：武侠、修仙、黑道

**设定框架**
```
姓名：[反派名字]
身份：
  - 旧敌（主角祖上/恩师的敌人）
  - 被主角杀死的反派亲属
  - 与主角有旧怨的人
性格特质：
  - 执念深重（仇恨驱使行动）
  - 阴狠毒辣（手段残忍）
  - 不择手段（不顾道德）
恶行/动机：
  - 复仇（向主角或主角亲近的人报复）
  - 毁灭（要彻底毁灭主角）
  - 折磨（让主角生不如死）
实力/优势：
  - 实力强大（往往比主角强）
  - 经验丰富（老谋深算）
  - 有强大势力支持
```

**经典案例**
- 血影门主（祖上恩怨）
- 黑虎帮老大（黑道复仇）
- 魔道长老（师门恩怨）

## 势力设定模板

### 1. 宗门设定
**适用场景**：修仙、武侠

**设定框架**
```
宗门名称：[如天剑宗、逍遥门]
宗门等级：
  - 一品宗门（顶级）
  - 二品宗门（一流）
  - 三品宗门（二流）
  - 等外宗门（底层）
核心功法：
  - 镇宗绝学（不传之秘）
  - 核心功法（核心弟子修炼）
  - 外门功法（外门弟子修炼）
势力结构：
  - 宗主（最高领袖）
  - 长老（分掌事务）
  - 核心弟子（精英）
  - 外门弟子（普通）
宗门规则：
  - 门规（必须遵守）
  - 晋升机制（晋升路径）
  - 赏罚制度（激励与惩罚）
```

**经典案例**
- 天剑宗（剑修宗门）
- 逍遥门（散修聚集）
- 药王谷（医术宗门）

### 2. 家族设定
**适用场景**：都市、古代、修仙

**设定框架**
```
家族名称：[如王家、李氏、萧家]
家族地位：
  - 顶级豪门（统治阶层）
  - 中等家族（有一定地位）
  - 底层家族（依附他人）
家族产业：
  - 核心产业（主要收入来源）
  - 次要产业（辅助收入）
  - 特殊资源（独占资源）
权力结构：
  - 族长（最高权力）
  - 长老（家族元老）
  - 核心成员（直系亲属）
  - 旁系成员（间接亲属）
家族恩怨：
  - 与其他家族的冲突
  - 内部权力斗争
  - 历史遗留问题
```

**经典案例**
- 王家（顶级豪门）
- 李氏（中等家族）
- 萧家（没落家族）

### 3. 组织设定
**适用场景**：现代、末世、科幻

**设定框架**
```
组织名称：[如暗影组织、光明会]
组织性质：
  - 正义组织（维护秩序）
  - 中立组织（利益优先）
  - 邪恶组织（追求私利）
组织规模：
  - 全球组织（遍布世界）
  - 区域组织（控制特定区域）
  - 地下组织（隐藏在暗处）
组织架构：
  - 领袖（最高领导者）
  - 核心成员（精英）
  - 普通成员（基础力量）
组织目标：
  - 维护秩序/制造混乱
  - 追求某种理想
  - 获取特定资源
```

**经典案例**
- 暗影组织（地下势力）
- 光明会（神秘组织）
- 猎人公会（赏金组织）

## 爽文类型参考

### 1. 逆袭流
**核心爽点**：从底层逆袭到巅峰
**适用场景**：修仙、都市、校园
**经典设定**：
- 废柴少爷→修仙天才
- 底层打工人→商界大佬
- 学渣→学霸

### 2. 打脸流
**核心爽点**：让轻视自己的人后悔
**适用场景**：修仙、都市、职场
**经典设定**：
- 扮猪吃虎，关键时刻爆发
- 被看不起，最后惊艳全场
- 敌人嚣张，最后被打脸

### 3. 系统流
**核心爽点**：系统帮助快速变强
**适用场景**：都市、末世、玄幻
**经典设定**：
- 神豪系统（金钱无限）
- 无敌系统（实力无敌）
- 收集系统（收集万物）

### 4. 穿越重生流
**核心爽点**：利用未来预知/现代知识
**适用场景**：历史、玄幻、都市
**经典设定**：
- 现代人穿越古代
- 重生弥补遗憾
- 改变历史进程

### 5. 种田流
**核心爽点**：慢慢发展，逐步壮大
**适用场景**：历史、种田、经营
**经典设定**：
- 经营种田，逐步富足
- 建立势力，逐步扩大
- 积累资源，逐步变强

### 6. 守护流
**核心爽点**：守护重要之人/事物
**适用场景**：修仙、都市、奇幻
**经典设定**：
- 守护家人
- 守护爱人
- 守护家园
