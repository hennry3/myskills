# 质量保证指南

## 质量控制清单使用说明

本指南提供详细的质量控制流程，确保生成内容的质量稳定性。

## 每章生成前必须确认

### 1. 信息回顾

**回顾前3章关键信息**
- 主角当前状态：实力、位置、心理状态、人际关系
- 当前情节进度：处于哪个阶段（开篇/发展/高潮），主要冲突是什么
- 已埋伏笔：有哪些伏笔已经埋下，需要在近期提及或回收

**如何回顾**
- 快速浏览前3章的结尾部分
- 提取关键信息：人物状态、当前冲突、待解决事项
- 在心中或笔记中记录：主角现在在哪里？在做什么？面临什么挑战？

**回顾示例**
```
第10章结尾：林萧刚击败王峰，实力提升到筑基初期，位于宗门广场，面临长老们的质疑。
第11章回顾要点：
- 主角状态：林萧，筑基初期，刚获胜，心情复杂
- 当前情节：击败师兄后的余波
- 主要冲突：与宗门长老的对峙
- 待解决：证明自己的实力，洗清冤屈
```

### 2. 情节类型确认

**情节类型定义**
- 推进型：推动剧情发展，推进冲突升级
- 展开型：展开人物关系，展开世界观
- 爽点型：释放爽点，满足读者期待
- 过渡型：连接两个高潮，调整节奏

**避免连续使用相同类型**
- 连续3章使用同一情节类型时，必须调整
- 建议节奏：推进→展开→爽点→过渡→推进...

**情节类型检查清单**
- [ ] 前一章是什么类型？
- [ ] 前两章是什么类型？
- [ ] 本章是否与前两章类型不同？
- [ ] 如果连续使用，是否已调整情节侧重点？

### 3. 爽点类型确认

**爽点类型**
- 扮猪吃虎、越级碾压、身世揭秘
- 反派打脸、资源垄断、荣耀加身
- 复仇闭环、其他

**避免单调重复**
- 连续3章使用同一爽点类型时，必须调整
- 建议：每5章内包含至少3种不同爽点类型

**爽点类型检查清单**
- [ ] 本章是否有爽点？
- [ ] 爽点类型是什么？
- [ ] 前两章的爽点类型是什么？
- [ ] 本章爽点类型是否与之前不同？

### 4. 字数目标确认

**字数要求**
- 目标：1500-2000字
- 最低：1500字
- 理想：1700-1900字

**字数分配**
- 开头：100-200字
- 核心：1000-1500字
- 结尾：200-300字

**字数检查清单**
- [ ] 字数目标是否明确？
- [ ] 字数分配是否合理？
- [ ] 有哪些扩充方法可以使用？

### 5. 状态快照

**主角当前状态**
- 实力等级：[如筑基初期]
- 位置：[如宗门广场]
- 心理状态：[如刚获胜，心情复杂]
- 人际关系：[与反派关系恶化，与部分长老关系缓和]

**当前阶段**
- 开篇：第1-10章（建立形象，引入冲突）
- 发展：第11-50章（实力提升，冲突升级）
- 高潮：第51章-终章（最终决战，结局）

**待解决冲突**
- 主要冲突：[如与宗门长老的对峙]
- 支线冲突：[如家族内部的反对声音]
- 待解决：[在本章需要推进哪些冲突]

**待回收伏笔**
- 已埋伏笔1：[如神秘戒指的来历]
- 已埋伏笔2：[如长老们的真实意图]
- 待提及：[哪些伏笔需要在本章提及]

## 每章生成后必须检查

### 基础检查

**字数检查**
- [ ] 字数是否≥1500字？
- [ ] 如果不足，哪些部分可以扩充？
- [ ] 优先扩充：心理描写、细节描写、对话

**情节连贯性检查**
- [ ] 本章开头是否与上一章结尾衔接？
- [ ] 情节推进是否合理？
- [ ] 因果关系是否清晰？
- [ ] 时间线是否正确？

**人物一致性检查**
- [ ] 主角性格是否一致？
- [ ] 反派性格是否一致？
- [ ] 配角行为是否符合设定？
- [ ] 人物关系是否有矛盾？

**爽点效果检查**
- [ ] 爽点是否达到预期？
- [ ] 铺垫是否充分？
- [ ] 爆发是否有力？
- [ ] 反应是否真实？

### 深度检查（每5章执行一次）

**人物一致性深度检查**

**主角一致性**
- [ ] 性格是否保持一致？（隐忍/桀骜/扮猪吃虎等）
- [ ] 说话风格是否统一？
- [ ] 行为模式是否合理？
- [ ] 成长路径是否按计划？

**反派一致性**
- [ ] 性格是否前后一致？
- [ ] 实力变化是否合理？
- [ ] 与主角的关系是否连贯？
- [ ] 崩溃/臣服的原因是否充分？

**配角一致性**
- [ ] 每个配角的性格是否稳定？
- [ ] 对主角的态度变化是否自然？
- [ ] 行为是否符合设定？
- [ ] 出场是否有意义？

**人物关系一致性**
- [ ] 主角与反派的关系是否连贯？
- [ ] 主角与配角的关系是否合理发展？
- [ ] 配角之间的关系是否一致？
- [ ] 势力关系是否符合设定？

**情节逻辑深度检查**

**时间线**
- [ ] 章节之间的时间顺序是否正确？
- [ ] 事件的发生时间是否合理？
- [ ] 有无时间跳跃的矛盾？
- [ ] 事件的持续时间是否合理？

**因果关系**
- [ ] 前因后果是否清晰？
- [ ] 事件的触发是否合理？
- [ ] 后果是否与原因匹配？
- [ ] 有无无中生有的情节？

**冲突升级**
- [ ] 冲突的升级是否自然？
- [ ] 冲突的解决是否合理？
- [ ] 支线冲突与主线冲突是否关联？
- [ ] 冲突的激烈程度是否得当？

**逻辑漏洞**
- [ ] 有无情节矛盾？
- [ ] 有无无法解释的事件？
- [ ] 有无逻辑不通的转折？
- [ ] 有无前后矛盾的设定？

**设定符合度深度检查**

**实力等级**
- [ ] 主角的实力成长是否符合设定？
- [ ] 反派的实力变化是否合理？
- [ ] 配角的实力是否一致？
- [ ] 实力差距是否保持？

**金手指**
- [ ] 金手指的能力是否符合设定？
- [ ] 金手指的解锁时机是否合理？
- [ ] 金手指的使用限制是否一致？
- [ ] 金手指的升级路径是否按计划？

**世界观**
- [ ] 世界规则是否保持统一？
- [ ] 势力关系是否符合设定？
- [ ] 场景描写是否一致？
- [ ] 特殊设定是否保持？

**资源**
- [ ] 资源的获取是否合理？
- [ ] 资源的消耗是否符合逻辑？
- [ ] 资源的数量是否连续？
- [ ] 资源的用途是否一致？

**伏笔回收深度检查**

**伏笔记录**
- [ ] 已记录所有已埋下的伏笔
- [ ] 已标记伏笔的类型和重要性
- [ ] 已预估伏笔的回收时机
- [ ] 已标记待回收伏笔

**伏笔回收**
- [ ] 伏笔是否被遗忘？
- [ ] 伏笔回收时机是否恰当？
- [ ] 伏笔揭示是否自然？
- [ ] 伏笔回收是否有力？

**新伏笔**
- [ ] 新埋下的伏笔是否有意义？
- [ ] 新伏笔是否与前文矛盾？
- [ ] 新伏笔是否有利于后续情节？
- [ ] 新伏笔是否已记录？

### 创新深度检查（每10章执行一次）

**情节类型多样性**
- [ ] 最近10章使用了哪些情节类型？
- [ ] 是否有过度使用的类型？
- [ ] 情节类型是否多样化？
- [ ] 是否需要调整后续章节的情节类型？

**人物成长深度**
- [ ] 主角的成长是否只是实力提升？
- [ ] 主角是否有心理成长？
- [ ] 主角的世界观是否有所变化？
- [ ] 主角的性格是否有发展？

**主题体现**
- [ ] 核心主题是什么？
- [ ] 主题是否在情节中得到体现？
- [ ] 主题是否在人物成长中得到体现？
- [ ] 主题是否有所升华？

**创新元素**
- [ ] 是否有反套路情节？
- [ ] 是否有意外转折？
- [ ] 是否有深度冲突？
- [ ] 是否有独特设定？

## 质量问题修正

### 小问题修正（口误、小矛盾）

**示例**
- 第10章：主角姓名写成"林晓"
- 第11章修正：用对话或旁白稍作说明
- 修正方式："林萧，不，是林晓..."（自我纠正）

**修正原则**
- 不影响主要情节
- 修正要自然
- 不要打断阅读流畅度

### 中等问题修正（情节偏差）

**示例**
- 第10章：主角实力提升过快，超出了设定
- 第11-12章：通过情节发展进行修正
- 修正方式：
  - 第11章：主角遭遇挑战，实力提升的效果不如预期
  - 第12章：主角发现问题，重新调整修炼方法

**修正原则**
- 在1-2章内修正
- 通过情节发展自然修正
- 不要直接修改已生成内容

### 大问题修正（核心设定矛盾）

**示例**
- 第10-15章：主角性格突然大变，与设定不符
- 修正方式：与用户沟通，确认是否需要重新调整

**修正原则**
- 与用户沟通确认
- 可能需要重新调整方向
- 不要擅自修改

## 常见质量问题

### 1. 字数不足

**原因**
- 情节推进过快
- 描写过少
- 对话过短

**修正方法**
- 增加细节描写（环境、动作、神态）
- 增加心理描写
- 增加对话内容
- 增加场景过渡描写

### 2. 情节不连贯

**原因**
- 章节之间缺乏衔接
- 时间线混乱
- 因果关系不清

**修正方法**
- 在章节开头回顾上一章结尾
- 明确时间线
- 梳理因果关系

### 3. 人物不一致

**原因**
- 性格设定不明确
- 行为偏离设定
- 关系矛盾

**修正方法**
- 建立人物卡片
- 定期回顾人物设定
- 保持人物行为一致性

### 4. 爽点不足

**原因**
- 铺垫不足
- 爆发不狠
- 反应不真

**修正方法**
- 增加铺垫篇幅
- 强化爆发描写
- 增加反应细节

## 质量保证流程

### 标准流程

1. **生成前**
   - 回顾前3章关键信息
   - 确认本章情节类型和爽点类型
   - 确认字数目标
   - 记录状态快照

2. **生成中**
   - 按照质量控制要求创作
   - 注意情节连贯性和人物一致性
   - 确保爽点达到预期

3. **生成后**
   - 执行基础检查
   - 每5章执行深度检查
   - 每10章执行创新深度检查
   - 根据检查结果修正问题

4. **定期回顾**
   - 每完成一个阶段（开篇/发展/高潮）
   - 进行全面的质量回顾
   - 修正发现的问题
   - 规划下一阶段的质量目标
