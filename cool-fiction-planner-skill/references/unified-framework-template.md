# 统一设定框架模板

## 使用说明
本模板为爽文小说的统一设定框架，支持：
1. 一键填充（AI自动生成所有内容）
2. 部分填充（用户填写关键，AI补充细节）
3. 完全自定义（用户完整填写）

- 每次生成数量：[建议1章]

**关键节点章节**

- 中期高潮章节：[第XX章]
- 最终决战章节：[第XX章]
- 结局章节：[第XX章]

### 5.2 生成策略
**质量要求**
- 每章必须包含详细描写（动作、心理、环境）
- 打斗场景必须过程详细（+500-800字）
- AI/系统互动必须推理详细（+300-500字）
- 爽点必须铺垫充分、爆发有力

**连贯性要求**
- 每5-10章进行一次连贯性检查
- 每章生成前回顾前3章关键信息
- 记录人物状态、当前情节、已埋伏笔

**创新深度要求**
- 人物有创新点（非典型性格/成长路径）
- 设定有创新点（混合世界观/独特规则）
- 情节有创新点（反套路/意外转折）
- 主题有深度（个人→群体，复仇→救赎）

## AI自动生成说明

当用户选择「由AI自动生成剩余所有设定」时，AI将：
1. 基于已填写的信息，自动填充剩余空白项
2. 确保所有设定之间的逻辑一致性
3. 提供至少3个创意选项供用户选择
4. 标注需要用户确认的关键设定

生成后，用户可以：
- 直接使用
- 微调部分设定
- 切换到逐个询问模式进行详细调整
